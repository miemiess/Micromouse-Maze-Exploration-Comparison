# 扩展阶段结果

扩展实验按[扩展实验计划](../../Docs/ext/experiment-plan.md)运行，计划注册在 `src/ext/plan.py`。运行前可加 `--dry-run` 预览地图、种子、规则、CSV 字段和输出目录（不运行、不写文件）：

```bash
python src/run_experiments.py --plan ext_turn --dry-run
python src/run_experiments.py --plan ext_noise --dry-run
```

- `--plan ext_turn` → `results/ext/turn/<子实验>/`：`lambda_0.5`、`lambda_1`、`lambda_2`、`lambda_4`、`motion_time`，测试集 435 张地图 × 10 个探索算法，计时重复 3 次。
- `--plan ext_noise` → `results/ext/noise/<子实验>/`：`ideal`、`high`、`mid`、`low`，噪声子集 200 张地图 × 2 个算法 × 5 个种子。
- `--plan ext_two_phase` → `results/ext/two_phase/<子实验>/`：`steps`、`lambda_2`，测试集 435 张地图 × 6 个算法（到达即停 3 个、有界提前停止 3 个）。
- `difficulty/`（D4，已生成）：`features.csv`、`correlations.md`（难度特征与基础实验 1 的相关，描述性）、`adversarial_<算法>.json / .md`（模拟退火对抗迷宫，可用上位机打开）。由 `python src/ext/difficulty.py features` 与 `adversarial --algorithm <名称>` 生成。

每个子实验包含 `runs.csv`、`summary.csv`、`summary.md`、`metadata.json` 和 `figures/`，格式与 `results/basic/` 相同；规则参数、撞墙上限与地图清单记录在 `metadata.json`，字段含义见[结果说明](../README.md)。归档前可加 `--out results/local/<目录>` 先写到本地。

X1～X3 的正式结果已生成（2026-11-22，计划冻结提交 e6e5e8e；运行期间只新增了分析脚本与上位机改动，算法与规则代码未变）。分析：`python src/ext/analysis.py` → [`analysis/report.md`](analysis/report.md)（配对胜负、符号检验、分组一致性）与 `analysis/*.png`（λ 曲线、噪声曲线、ε 曲线）。

## 主要结论（按冻结计划第 5 节判定，详见 [`analysis/report.md`](analysis/report.md)）

- **Q1 把转弯代价纳入规划**：朝向 A* 与重复 A* 在 λ = 0.5、1、2、4 和运动时间下逐图胜负接近（如 λ = 2 为 186 胜 / 168 负），**均无显著差异**。在未知地图上，按规则代价规划并没有带来可测的好处：探索阶段的代价主要由“被乐观假设误导后的绕路”决定，而不是转弯。
- **Q2 排名**：基础阶段的结论基本成立。重复 A* 在 λ ≤ 1 时平均代价比最低，λ ≥ 2 与运动时间下加权朝向 A*（w = 2）以微弱优势居首（与 w = 1 的配对差异不显著，见 Q3）；乐观重规划类算法始终领先，DFS、沿墙法、前沿探索最差，且差距随 λ 增大而扩大。
- **Q3 加权 A***：w = 2 在所有规则下扩展状态数**显著更少**（如 λ = 2 时 350 胜 / 84 负），代价比**无显著差异**——用加权换计算量在这里几乎没有代价。
- **Q4 D* Lite**：计算时间**显著更长**（中位数 5.2 ms 对重复 A* 的 2.1 ms），78% 的地图路线完全相同。在 16×16 地图上，增量修复的簿记开销超过了它省下的搜索。
- **Q5 置信度融合**：与只信最近读数相比，各档噪声下步数**无显著差异**；低准确率时撞墙次数反而**显著更多**（425 胜 / 517 负）。累积证据在当前设定下没有体现优势（乐观假设下未知边仍视为可走，撞墙是主要的纠错手段）。
- **Q6 噪声代价**：所有运行都到达目标；步数 / 最短路从理想观测的 2.14 升到高、中、低三档的约 3.8、4.9、5.5～5.8，每局撞墙约 20、34、46～48 次。
- **Q7 两阶段比赛**：有界提前停止的冲刺 / 最优在每张地图上都满足 ≤ 1 + ε（理论保证成立）。平均成绩明显更低（步数代价 54.0～55.5 对“到达即停”约 61；λ = 2 时 104.8～107.1 对约 120），外部迷宫库上显著更好；生成图上多数比较胜负接近，因此多数结论按规则记为“取决于地图来源”。ε 从 0 增到 0.25 时探索代价下降、冲刺变长，成绩小幅变差，ε = 0 最好。
算法实现与固定迷宫的验收示例见[扩展算法说明](../../src/ext/README.md#已实现的算法)。
