# 扩展实验计划

实验使用同一批测试地图，按研究问题分成两套计划。

| 入口 | 研究问题 | 条件与规模 |
| --- | --- | --- |
| `ext` | E1/E3 中，代价规则会怎样改变各策略的成功率、路线代价和计算用时？ | 基础规则、转弯代价、运动时间，共 9,135 条记录 |
| `ext-noise` | E2 中，融合多次墙面读数能否减少误判、撞墙和移动开销？ | 理想读数、默认噪声、增强噪声，共 13,050 条记录 |

先用预览核对设置，再启动正式运行。两套计划分别归档。

## 地图划分

| 来源 | 开发集 | 测试集 |
| --- | ---: | ---: |
| 外部迷宫库 | 79 张 | 315 张 |
| 生成迷宫 | 120 张，种子 101–110 | 120 张，种子 1–10 |
| 合计 | 199 张 | 435 张 |

外部地图先按文件名排序，再用 `random.Random(2026)` 抽取 79 张作为开发集，其余作为测试集。名单固定在 [ext_dev.json](../../mazes/splits/ext_dev.json)。生成迷宫覆盖四种生成器和 0%、10%、30% 三档环路比例。划分只用于扩展阶段。同一批外部地图已用于基础阶段，扩展测试集与本次开发集分离。

## E1/E3 代价对照

| 输出子目录 | 规则 |
| --- | --- |
| `baseline/` | 基础规则，每次成功移动的代价为 1 |
| `turn_cost/` | 每步代价 1，每次 90° 转向代价 2 |
| `motion_time/` | 格长 0.18 m，最高速 0.5 m/s，加速度 2 m/s²，90° 转向 0.3 s，掉头 0.5 s |

转弯权重沿用 E1 验收示例的 λ = 2。运动参数沿用 E1 的仿真设置。加权朝向 A* 固定 w = 2，与 w = 1 成对比较。本轮采用上述固定参数，不做数据驱动选参。若开展调参，预先登记参数候选和选择标准，在开发集上选定后再跑测试集。

对照组为 DFS、Flood-Fill 和重复 A*。扩展组为朝向 A*、加权朝向 A*、D* Lite 和最近前沿探索。每个条件有 435 × 7 = 3,045 条记录。所有策略接收理想观测，首次撞墙终止，种子为 0，使用默认的 20 × 格子数动作预算和 30 秒策略计算预算。每个组合重复 3 次，计算耗时取中位数，核对终止状态、路径及动作统计是否一致。

### 评价与比较

- 按地图来源、生成器和环路比例分组，报告成功率和终止状态分布。移动步数、转向和重复访问用于解释路线差异。
- 在基础条件下比较成功运行的步数与已知地图最短步数之比。在代价模型下比较成功运行的实际规则代价与同规则最优代价之比。
- 比较同一环境中的计算耗时。两个朝向 A* 变体可直接比较扩展状态数。D* Lite、最近前沿和朝向 A* 的搜索状态定义不同，节点计数结合实现解释。
- 比较两种朝向 A* 的搜索权重时，先核对成功率，再比较扩展状态数与实际规则代价。比较同一策略在不同规则下的表现时，按同一张地图配对，使用各条件自己的最优代价作为分母。补充动作数、碰撞次数和成功路径的移动指标。

## E2 噪声与置信度对照

| 输出子目录 | 前方 / 侧向 / 后方准确率 | 碰撞处理 |
| --- | --- | --- |
| `perfect_sensor/` | 1 / 1 / 1 | 可恢复，次数不限 |
| `default_sensor/` | 0.95 / 0.90 / 0.85 | 可恢复，次数不限 |
| `stress_sensor/` | 0.90 / 0.80 / 0.70 | 可恢复，次数不限 |

三个条件均采用单位移动代价和同一个噪声层。理想读数条件把传感器准确率设为 1，以便固定碰撞策略。后两档准确率是仿真假设，分别用于默认场景和压力测试。噪声模型按地图 ID 和种子初始化。两种算法使用同样的种子集合，各自接收运行过程中实际访问位置的读数。

每个条件对比 `belief_astar` 与 `belief_astar_naive`，执行 435 张地图 × 2 种算法 × 5 个种子（0–4），共 4,350 条记录。每个组合运行一次，保留不同种子带来的波动。动作和策略计算预算与 E1/E3 相同。

先比较成功率和终止状态分布，再比较全体运行的动作数、碰撞数，以及成功运行的步数比。按同一地图和种子配对比较两种算法。报告每个条件下的种子均值与种子间标准差，保留各地图组的结果。各条件的撞墙上限固定，这组结果用于分析噪声和置信度融合的影响。

## 接口与导出

在仓库根目录运行。预览输出为 JSON，包含每个子实验的完整规则规格和碰撞上限、地图文件列表、算法、种子、预算、重复次数、预计记录数、计时运行次数、CSV 列名及输出路径。预览不运行策略或创建结果目录。

```bash
python src/run_experiments.py --plan ext --dry-run
python src/run_experiments.py --plan ext-noise --dry-run
python src/run_experiments.py --plan ext --out results/local/ext-review
python src/run_experiments.py --plan ext-noise --out results/local/noise-review
```

默认输出分别位于 `results/ext/` 与 `results/ext/noise/`。正式计划固定规则、地图、算法、种子和预算等设置，命令行可通过 `--out` 指定输出目录，或用 `--no-plot` 跳过图表。自选实验可直接指定 `--rule`、`--maps`、`--algorithms`、`--seeds` 等参数。

| 文件 | 数据口径 |
| --- | --- |
| `metadata.json` | 与预览共用配置字段，附实际记录数 `runs`、运行时间、代码版本和平台 |
| `runs.csv` | 每个地图、算法和种子组合一行，记录终止状态、成功移动数、动作数、碰撞数、计算耗时和重复一致性等 |
| `summary.csv`、`summary.md` | 按地图组和算法汇总成功率、步数比、碰撞等指标。规则代价条件还汇总同规则代价比 |
| `figures/` | 基于汇总数据的成功率、步数比和计算用时图，代价条件另含规则代价比图 |

核对每个条件的 `runs == expected_rows`，检查地图、算法、种子组合唯一，E1/E3 的三次行为重复一致。失败运行留在原始数据中，成功路径比值留空。用 `runs.csv` 核对终止状态分布、按地图与种子配对，并汇总种子间的离散程度。归档时记录干净的代码提交和运行环境，再把正式对照结果写入报告。
