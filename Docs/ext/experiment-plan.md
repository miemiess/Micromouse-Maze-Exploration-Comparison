## 1. 要回答的问题

| --- | --- | --- | --- |
| Q1 | 把转弯代价纳入规划，实际代价是否更低？随 λ 增大，差距如何变化？ | `turn_aware_astar` vs `repeated_astar` | X1 |
| Q2 | 基础阶段的算法排名在转弯代价 / 运动时间下是否改变？ | 10 个算法的平均代价比排名 | X1 |

| Q5 | 噪声下累积证据是否比只信最近读数更好？准确率下降时如何变化？ | `belief_astar` vs `belief_astar_naive` | X2 |

## 3. 实验设置

| 实验 | 规则（子实验） | 算法 | 种子 / 重复 | 预计耗时 |
| --- | --- | --- | --- | --- |
| **X1** `--plan ext_turn` | 转弯代价 λ = 0.5、1、2、4；运动时间模型（默认参数） | 基础：dfs、flood_fill、greedy_dfs、repeated_astar、wall_follower_left、prior_astar；扩展：turn_aware_astar、turn_aware_astar_w2、dstar_lite、frontier | 种子 0；计时重复 3 次取中位数 | 约 15 分钟 |
| **X3** `--plan ext_two_phase` | 两阶段比赛：步数代价（`two_phase`）、λ = 2 转弯代价（`turn_cost:weight=2+two_phase`）；成绩 = 冲刺 + 探索（含返回起点）/ 30 | 到达即停：repeated_astar、flood_fill、turn_aware_astar；有界提前停止：bounded_explore_e0、e10、e25 | 种子 0，不重复计时 | 约 20 分钟 |
| **X4** `python src/ext/difficulty.py` | 基础规则 | 特征相关：基础实验 1 的全部探索算法；对抗生成：repeated_astar（1500 次）、flood_fill（1000 次），种子 0 | — | 约 5 分钟 |
| **X2** `--plan ext_noise` | 理想观测（对照）；噪声三档：高 0.95 / 0.90 / 0.85、中 0.90 / 0.80 / 0.70、低 0.80 / 0.70 / 0.60（前 / 侧 / 后准确率）；撞墙后继续、不限次数 | belief_astar、belief_astar_naive | 种子 0～4（同一种子噪声相同，两种算法配对比较） | 约 30 分钟 |

- 动作预算为默认的 20 × 格子数。
- **不调参**：λ 和准确率是场景参数，不是算法参数；w = 2 事先固定；运动时间与传感器参数用默认的仿真假设值。因此扩展阶段没有调参步骤。
- 算法在计划冻结后不再修改；需要改进的算法只在开发集上调试，改完要作为新算法或新版本，并重跑全部实验。

## 4. 指标

| 指标 | 定义 | 用于 |
| --- | --- | --- |
| 代价比 | 实际规则代价 / 已知地图上的规则最优代价（只统计成功的运行） | Q1、Q2、Q3（主指标） |
| 步数比 | 步数 / 最短路 | Q5、Q6（主指标，噪声实验不叠加代价层） |
| 成功率 | 状态为 success 的比例 | 全部 |
| 撞墙次数 | collisions | Q5、Q6 |
| 计算时间 | 算法决策累计耗时，3 次重复的中位数（毫秒） | Q3、Q4 |
| 扩展状态数 | 算法 stats() 的 expanded_nodes（只在实现了它的算法之间比较） | Q3 |
| 成绩 | 冲刺代价 + （探索代价 + 返回起点代价）/ 30；另报冲刺 / 最优、探索代价 | Q7（主指标） |
| 难度特征 | 环路比例、死胡同比例、分岔比例、最短步数、绕路系数、最短路转向数（定义见 `src/ext/difficulty.py`） | Q8 |

## 5. 结论标准（事先确定）

- **配对比较**：X1 按地图配对，X2 按（地图, 种子）配对；只用两种算法都成功的配对。差值绝对值小于 10⁻⁹ 记为平局，其余计胜 / 负。
- **显著性**：对胜负次数做双侧符号检验，p < 0.05 才写“更好 / 更差”，否则写“无显著差异”。
- **分组一致**：外部迷宫库和生成图两组分别报告；只有两组方向一致时才写成总体结论，不一致时如实写“取决于地图来源”。
- **Q2 排名**：按平均代价比排序，报告每档规则下的前三名。与基础阶段比较时，只说“最优算法是否改变”，不对微小的排名差异下结论。
- **Q4 路线**：报告路线完全相同的地图比例；计算时间用中位数比较。
- **Q7**：成绩按地图配对比较（同第一条）；另验证理论保证——有界提前停止的冲刺 / 最优 ≤ 1 + ε 必须在每张地图上成立，否则视为实现错误。
- **Q8**：只报告 Spearman 相关系数与对抗迷宫上各算法的表现，作为描述与案例，不写因果或显著性结论。
- 成功率不同的算法，代价比只能作参考，正文要同时给出成功率。
