# 项目文档

- `Project_Brief.pdf`：用户提供的课程原始要求，按原文件保存。
- `Micromouse_Project_Proposal.pdf`：当前多算法与自主设计方案概要，包含目标、源码、任务与交付；不是批准通知。
- `experiment-plan.md`：实验前确定的指标、预算、测试集与开发集（D1），C2 新方案在实验 1 中评估，开发集只用于调参。
- `algorithm-methods.md`：全部已实现算法的登记（B1）。
- `algorithm-design.md`：本组提出的先验增强重复 A* 的设计、证明、调参与消融结果（C1/C2）。
- `demo-guide.md`：安装、命令与答辩演示步骤（D3）。
- `Result.md`：最终报告中文初稿（全员共同撰写，定稿后译为英文）。

任务分工以仓库首页为准。文档类文件统一放在本目录，保持扁平结构。
