# 本组提出的策略：先验增强的重复 A*（C1）

> 适用规则：本项目的**基础规则**——16×16 地图，起点 (0, 0) 朝北，中央 2×2 目标，到达任一目标格即成功；每次跨格移动代价为 1，转向只计数、不计入代价；理想观测（到达一格即知道该格四面墙）。
> 代码：`src/basic/algorithms/prior_astar.py`（C2）；测试：`tests/test_basic/test_algorithms.py` 中的 `PriorAStarTests`；实验：与其他算法一起在实验 1 中运行，结果见 `results/basic/main/`（消融图 `figures/ablation_prior_astar.png`）；开发集记录见 `results/basic/dev/`。
> 与已有工作的关系：乐观假设与按需重规划来自重复 A*（见 `Docs/basic/algorithm-methods.md`）；柱子规则来自比赛规程（除目标区外没有 2×2 空地）；“对不确定的边加代价”是风险规避规划中的常见思路。本组的工作是把它们放进同一个可消融的框架，并提出按在线估计的墙密度自适应调整惩罚。在完成文献核查前称为“本组提出的变体”，不宣称首创。

## 1. 设计动机

第 2 章实验中，重复 A* 和 Flood-Fill 是最好的两种探索算法，但它们在部分地图上仍要走最短路的数倍（外部迷宫库最大 28.1 倍，Wilson 无环图均值 2.9 倍）。原因是同一个**乐观假设**：未知边一律当作通路。小车会朝“看起来最短”的方向走，结果被一面没看到的墙挡住，只好折返。

所以要回答的问题是：**在单位步长代价下，能不能少被未知边误导？** 可以从两个方向下手：

1. **少一些未知**：用迷宫的结构规律，从已看到的墙推出还没看到的墙。
2. **少相信未知**：规划时不再把未知边和已确认的通路一视同仁。

## 2. 先排除的方案（基础规则下不改变决策）

README 和第 4 章初稿列出的几个候选，在基础规则下可以证明**不会改变重复 A* 的任何决策**，因此没有实现。这本身是分析结论，写入报告。

| 候选 | 为什么在基础规则下无效 |
| --- | --- |
| 转弯代价 λ、ε 提前停止（第 4 章初稿） | 基础规则下转弯不计代价（λ = 0），也没有冲刺阶段；方案退化为重复 A* |
| 已知死胡同剪枝 | 不是目标的死胡同格在已知地图中只有一个出口，任何**简单**路径进入它就出不来，所以它不可能出现在通往目标的最短路线上；A* 本来就不会规划进去，剪枝只省计算、不省步数 |
| 目标区“只有一个入口”先验 | 观测是整格四面墙：要看到某个入口是开的，小车必须已经站在入口外的格子上，下一步本来就会进去；看到入口外有墙也不需要这条先验。推断出的信息总是来得太晚 |

## 3. 方案

在重复 A*（乐观地图、按需重规划）的基础上加两个**可分别开关**的机制。

### 3.1 机制 1：柱子规则推断墙（结构先验）

比赛规程要求：除目标区中心外，每根内部柱子至少连着一面墙（等价于除目标区外没有 2×2 的空地）。

- **推断**：一根柱子连着 4 条边。如果其中 3 条已确认无墙、第 4 条未知，就推断第 4 条是墙，记为**软墙**。外边界上的柱子和目标区中心的柱子不受约束。
- **软墙只影响规划**：规划时软墙不可走；计划被软墙挡住也会重新规划。
- **自我关闭**：一旦观测到某根柱子四边都无墙（包括软墙被观测推翻），说明这张迷宫不守比赛规程（例如 10%、30% 环路的生成图），本次运行就清空软墙、关闭机制 1，退化为普通乐观假设。

**安全性（可证明）**：软墙不会让乐观地图断开。软墙 e 的两个端点已经由同一柱子的另外 3 条边相连，这 3 条边都是**观测到的通路**，而观测到的通路永远不会被推断为墙。因此去掉任意一组软墙，乐观地图的连通性不变：推断错误最多让路线变长，不会导致失败，也就不需要“无路时退回”的分支。

### 3.2 机制 2：自适应未知边惩罚

- **代价**：已确认的通路代价为 1，未知边代价为 1 + δ（已知墙、软墙不可走）。δ = 0 时就是重复 A*；δ > 0 时，规划会在“已确认能走的路”和“看起来更短但没确认的路”之间权衡。
- **自适应**：δ 不取常数，而是按目前为止已观测的内部边估计“未知边是墙”的概率：

  p = (已观测墙数 + 1) / (已观测内部边数 + 2)（Beta(1, 1) 平滑），δ = c · p / (1 − p)

  墙越密，未知边越可能是墙，越应该偏向已确认的通路；在开阔的迷宫里惩罚自动变小。p/(1 − p) 是“是墙”对“是通路”的几率，c 是唯一的参数。
- **启发式仍可采纳**：所有边代价 ≥ 1，曼哈顿距离不会高估，A* 仍返回当前乐观加权地图上的最优路线。

### 3.3 伪代码

```text
reset：已知墙 W = ∅，已知通路 O = ∅，软墙 S = ∅，计划 plan = 空，规则开启 = use_post_rule
每一步（当前格 v，观测到 v 的四面墙）：
    for v 的每个方向 d：
        边 e = (v, v+d)
        if d 有墙：W ← W ∪ {e}；S ← S \ {e}
        else：O ← O ∪ {e}；if e ∈ S：关闭规则（S ← ∅）
    if 规则开启：
        for v 的 4 个角上的柱子 q（不含外边界、目标区中心）：
            if q 的 4 条边都 ∈ O：关闭规则（S ← ∅）
            elif q 的边都不在 W ∪ S，且恰有 3 条 ∈ O：S ← S ∪ {第 4 条}
    if plan 已走到 v：去掉 plan 的第一格
    if plan 为空 or plan 上有边 ∈ W ∪ S：
        δ = c · p / (1 − p)                       # 或固定 δ（消融）
        plan = A*(v → 目标, 不可走 = W ∪ S, 代价：e ∈ O 为 1，否则 1 + δ, 启发 = 曼哈顿)
        if plan 不存在：return None（no_path）
    return plan 的下一格方向
```

### 3.4 性质与复杂度

- **完备性（可证明）**：与重复 A* 相同。每次重新规划要么沿计划前进，要么至少新确认一面墙（或关闭规则）；墙是有限的，因此目标可达时必在有限步内到达。软墙不改变连通性（3.1 节）。目标不可达时，乐观地图上的 A* 终将失败，返回 None。
- **退化（有测试验证）**：两个机制都关闭时，A* 的堆排序键（f, h, 入堆序号）和邻格顺序与 `astar.astar_search` 完全相同，每张地图上的路线与 `repeated_astar` 逐格一致（`test_both_mechanisms_off_equals_repeated_astar`）。所以消融结果中的差异完全来自新增机制。
- **复杂度**：每次规划最坏 O(V log V)；每步推断只检查当前格 4 根柱子，O(1)；额外内存 O(V)（已知通路与软墙）。δ > 0 会改变规划次数，实际计算量由实验 1 测量。
- **不保证更好**：δ > 0 意味着有时会放弃更短的乐观路线去走确认过的路，在乐观假设恰好正确的地图上会多走路。这是有意的取舍，需要实验检验得失。

## 4. 调参与评估方法

按实验计划（`Docs/basic/experiment-plan.md` 第 4 节）在看测试结果之前确定：

- **开发集**：种子 101～110 生成的 120 张地图（4 种生成器 × 环路 0 / 10 / 30%），与测试集不重叠。
- **唯一参数**：c（候选 0.5～5）；消融用的固定 δ 另调（候选 0～3）。选取标准为开发集“步数 / 最短路”均值最低。记录见 `results/basic/dev/tuning.md`（可用同目录 `tune_dev.py` 复现），这是开发集的唯一结果。
- **冻结**：c = 2.5，固定 δ = 2.5，写入 `src/basic/algorithms/prior_astar.py` 后不再修改。
- **测试集**：实验 1 的 514 张地图；新方案和消融变体与其他算法在同一次运行中执行，每个组合 3 次（计时取中位数）。
- **消融**：

  | 变体 | 柱子规则 | 未知边惩罚 |
  | --- | --- | --- |
  | `repeated_astar`（基线） | 关 | 无（δ = 0） |
  | `prior_astar_no_penalty` | 开 | 无 |
  | `prior_astar_no_post` | 关 | 自适应 |
  | `prior_astar_fixed` | 开 | 固定 δ = 2.5 |
  | `prior_astar`（完整版） | 开 | 自适应 |

- **开发集上的观察**：开、关柱子规则，120 张开发地图的路线完全相同。它在 10% / 30% 环路图上常被观测推翻而关闭；在无环图上虽然推断出了软墙（平均每张约 4 面），但没有改变任何决策。原因是：推断出的边 nw–ne 所在的柱子，其另外 3 条边已确认无墙，说明小车已到过下方相邻的两格；从那里经下方绕过去与直接走 nw–ne 步数相同，只有从外侧横穿这个 2×2 块的路线才会受影响，这种情况很少。机制 1 在比赛规程的外部迷宫库上是否有用，由测试集回答。

## 5. 测试集结果

完整的消融表与分析见报告 [`Docs/Result.md`](../Result.md) 第 4.4、4.5 节（表 3），数据来自 `results/basic/main/`（消融图 `figures/ablation_prior_astar.png`）。要点：

- **整体没有达到设计目标**：全部 514 张地图上，完整版均值 2.318、中位数 2.019，都比重复 A*（2.172、1.714）差。
- **柱子规则几乎无用**：只改变了 3 张外部迷宫库地图的路线，与第 4 节的机理分析一致。
- **未知边惩罚用典型情况换最坏情况**：在生成图上能推广到测试集；在外部迷宫库上 261 张变差、69 张变好，最大比值从 28.1 降到 19.4。
- **自适应没有额外收益**：两类地图的墙密度相近，学到的 δ 也相近。
- **方法教训**：开发集只有生成图，参数在外部迷宫库上失效（分布偏移）；开发集应按地图来源分层。
- **事后分析**（看过测试结果后做的，不是正式结论，`results/basic/dev/posthoc.md`）：把 20% 外部迷宫库地图加入开发集后，调参选出 c = 0（关掉惩罚），在留出集上与重复 A* 几乎相同。分层开发集能避免这次失效，但新方案仍没有超过重复 A*。
